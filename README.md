# Timing Belt Guide

A practical technical reference for automotive timing belts, covering timing belt types, tooth profiles, sizing, materials, manufacturing, identification, failure analysis, and replacement selection.

Maintained by [REALSHOW BELT](https://chinarealshow.com/), an automotive and industrial belt manufacturer established in 2000.

## What Is a Timing Belt?

A timing belt is a toothed power-transmission belt designed to synchronize the rotation of components in an engine or mechanical system.

In automotive applications, a timing belt commonly synchronizes the crankshaft and camshaft. Its toothed construction allows the belt to maintain a defined relationship between rotating components when the correct belt, tooth profile, tension, and installation conditions are used.

For a broader overview of automotive belt types, see the [Automotive Belt Guide](https://chinarealshow.com/automotive-belt-guide/).

## Timing Belt Types

Automotive timing belts can be classified by tooth profile, pitch, construction, material, and application.

Common timing belt families include:

* HTD timing belts
* T-series timing belts
* Metric timing belts
* Automotive rubber timing belts
* High-temperature timing belts
* Application-specific timing belt designs

Different profiles are not interchangeable simply because their dimensions appear similar. Tooth geometry, pitch, width, length, and pulley compatibility all need to be considered.

Learn more about timing belt profiles and classifications in the [Timing Belt Types Guide](https://chinarealshow.com/timing-belt-types/).

## Timing Belt Tooth Profiles

The tooth profile determines how the belt engages with the timing pulley.

Important profile parameters include:

* Tooth shape
* Tooth pitch
* Tooth depth
* Tooth width
* Tooth spacing
* Pulley groove geometry

Common timing belt profile families include HTD and T-series designs.

A replacement timing belt should match the required tooth profile and pitch rather than being selected only by overall belt length.

## Timing Belt Size Explained

Timing belt size is generally described using several dimensional parameters rather than a single number.

Important specifications include:

| Specification   | Meaning                                                         |
| --------------- | --------------------------------------------------------------- |
| Tooth pitch     | Distance between corresponding points of adjacent teeth         |
| Number of teeth | Total number of belt teeth                                      |
| Belt length     | Pitch-length or applicable reference length                     |
| Belt width      | Nominal belt width                                              |
| Tooth profile   | Geometry of the belt teeth                                      |
| Material        | Rubber or other belt construction material                      |
| Reinforcement   | Tensile cord used to provide strength and dimensional stability |
